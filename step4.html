রসমভিত্তিক প্রাক-গ্রাম্যাটিক্যাল কোর-সেমান্টিক পদ্ধতি
"আরবি ভাষা ও কুরআনের শব্দার্থ বিশ্লেষণের একটি গবেষণা-প্রস্তাব"
ধাপ ৪. কোর-সেমান্টিক মানচিত্র ও আরবি অক্ষরের ধারণাগত ধারা

ভূমিকা

পূর্ববর্তী ধাপগুলোতে আলোচনা করা হয়েছে যে, রসম-ভিত্তিক প্রাথমিক আরবি ভাষায় শব্দই ছিল অর্থের প্রত্যক্ষ বাহক এবং রুট ছিল একটি বিশ্লেষণী কাঠামো। এখন প্রশ্ন হলো— শব্দের সেই কেন্দ্রীয় ধারণা (Conceptual Core) কীভাবে গঠিত হয়?

এই গবেষণায় একটি ব্যাখ্যামূলক (interpretive) মডেল প্রস্তাব করা হচ্ছে, যেখানে আরবি বর্ণমালার প্রতিটি অক্ষরকে একটি সম্ভাব্য ধারণাগত দিক (semantic direction) হিসেবে বিবেচনা করা হয়েছে। এই মডেল কোনো প্রতিষ্ঠিত ঐতিহাসিক সত্য হিসেবে নয়; বরং একটি পুনর্গঠনমূলক (reconstructive) সেমান্টিক মডেল হিসেবে উপস্থাপিত হচ্ছে, যার কার্যকারিতা কুরআনের শব্দসমূহে ধারাবাহিকভাবে প্রয়োগ করে পরীক্ষা করা যেতে পারে।

কোর-সেমান্টিক মানচিত্র ও ২৮ অক্ষরের আদি শক্তি

নিচের ২৮ অক্ষরের কোর-সেমান্টিক মানচিত্রটি আমার গবেষণাভিত্তিক একটি reconstructive semantic model। এটি প্রতিষ্ঠিত আরবি ভাষাবিজ্ঞানের স্বীকৃত তত্ত্ব নয়; বরং কুরআনিক শব্দগুলোর অভ্যন্তরীণ সামঞ্জস্য পরীক্ষা করার জন্য প্রস্তাবিত একটি বিশ্লেষণী কাঠামো। এই ২৮টি অক্ষরের প্রস্তাবিত সেমান্টিক মানচিত্রকে আরবি ভাষার একটি সম্ভাব্য প্রি-গ্রাম্যাটিকাল কোর-ধারা হিসেবে দেখা যেতে পারে, যা শব্দগঠনের পুনরাবৃত্ত প্যাটার্ন ব্যাখ্যায় কার্যকর একটি বিশ্লেষণী মডেল প্রদান করে। যে ধারায় আরবি শব্দ বারবার নিজেকে প্রকাশ করে।

আরবি ভাষার ২৮টি মূল অক্ষর নিচে দেওয়া হলো এবং প্রতিটি অক্ষরের পাশে নির্দিষ্ট, সংক্ষিপ্ত ধারার সম্ভাব্য শব্দগুচ্ছ। এগুলোকে কোর ধারা হিসেবে দেখা যেতে পারে:

১) আলিফ (ا)
অস্তিত্ব / সূচনা / প্রতিষ্ঠা / দাঁড়িয়ে থাকা / লক্ষ্য / অভিমুখ / উপস্থিতির ঘোষণা / সরল উত্থান / কেন্দ্রীয় দণ্ড।
২) বা (ب)
সংযুক্তি / সংলগ্নতা / ভেতরে প্রবেশ / ধারণের ভিতর / আশ্রয় / মাধ্যম / অবস্থানগত নিকটতা / পরিবেষ্টিত থাকা।
৩) তা (ت)
চলন / কার্যপ্রবাহ / সক্রিয়তা / ক্রিয়া-উৎপত্তি / ধারাবাহিক কর্ম / রূপান্তরমুখী গতি / কাজের সূচনা।
৪) ছা (ث)
বিস্তার / বহুগুণ / সংখ্যাগত বৃদ্ধি / ছড়িয়ে যাওয়া / পুনরুৎপাদন / স্তরবৃদ্ধি / প্রসারিত পুনরাবৃত্তি।
৫) জীম (ج)
সংগ্রহ / একত্রকরণ / আবরণ / ভেতরে ধরে রাখা / সংহত সঞ্চয় / গোপন ধারক / আবদ্ধ সমষ্টি।
৬) হা (ح)
জীবন্ততা / উষ্ণ উপস্থিতি / প্রাণশক্তি / কোমল স্পন্দন / সজীব প্রবাহ / জীবনীশক্তির প্রকাশ।
৭) খা (خ)
বহির্গমন / ভেদ করে বের হওয়া / অন্তর ভাঙন / আভ্যন্তরীণ থেকে বাহিরে গমন / উন্মোচন / বিচ্ছিন্ন উদ্গমন।
৮) দাল (د)
নির্দেশ / ঠেলা / ইঙ্গিতমূলক অগ্রগতি / দিকনির্দেশনা / ধাক্কা দিয়ে এগোনো / চালনাশক্তি।
৯) যাল (ذ)
ইঙ্গিত / স্মরণযোগ্যতা / চিহ্নিত উপস্থিতি / লক্ষণ / অবশিষ্ট চিহ্ন / মনে জাগ্রত করা।
১০) রা (ر)
প্রবাহ / পুনরাবৃত্ত গতি / ঘূর্ণন / চলমান সম্পর্ক / ধারাবাহিক প্রত্যাবর্তন / গতিশীল সংযোগ।
১১) ঝা (ز)
কম্পন / তাড়না / উত্তেজিত স্পন্দন / সঞ্চালিত শক্তি / উদ্দীপক নড়াচড়া।
১২) সীন (س)
ধারাবাহিক গতি / মসৃণ অগ্রসরতা / নিয়মিত চলন / ধাপে ধাপে অগ্রগতি / স্থিতিশীল প্রবাহ।
১৩) শীন (ش)
ছড়িয়ে পড়া / বিকিরণ / বিস্ফোরিত বিস্তার / বহু দিকে ছড়ানো / অপ্রতিরুদ্ধ সম্প্রসারণ।
১৪) সদ (ص)
সংহত চাপ / কেন্দ্রীভূত শক্তি / নিয়ন্ত্রিত বল / দমনমূলক স্থায়িত্ব / একমুখী জোর।
১৫) দদ (ض)
বিরোধী চাপ / বিপরীত বল / সংঘর্ষমূলক প্রতিক্রিয়া / প্রতিহতকারী শক্তি / বিপরীতমুখী চাপ।
১৬) ত্বা (ط)
আবদ্ধ শক্তি / কর্তৃত্ব / নিয়ন্ত্রিত আধিপত্য / কঠোর নিয়ামক বল / বদ্ধ ক্ষমতা।
১৭) য্বা (ظ)
আচ্ছাদিত কর্তৃত্ব / ছায়াঘেরা শক্তি / অস্পষ্ট আধিপত্য / পরোক্ষ নিয়ন্ত্রণ / আড়ালকৃত ক্ষমতা।
১৮) আইন (ع)
উৎস / চোখ / উন্মুক্ত গভীরতা / প্রত্যক্ষ উপলব্ধি / দৃশ্যমান গভীর কেন্দ্র / নির্গমনের মূলবিন্দু।
১৯) গ়াইন (غ)
আড়াল / অদৃশ্য গভীরতা / লুকায়িত উৎস / পর্দাবৃত গভীরতা / অপ্রকাশিত স্তর।
২০) ফা (ف)
বিচ্ছেদ / ফলন / উদ্গম / আলাদা হয়ে বের হওয়া / সিদ্ধান্তমূলক ফল / তাত্ক্ষণিক উৎপাদ।
২১) ক্বাফ (ق)
গভীর আঘাত / চূড়ান্ত সীমা / কেন্দ্রীয় সংঘাত / গভীর থেকে সৃষ্ট প্রতিক্রিয়া / শক্ত সংযোগবিন্দু।
২২) কাফ (ك)
ধারণক্ষমতা / আকৃতি দেওয়া / ছাঁচ নির্মাণ / সক্ষমতা / কাঠামোগত ধারণ।
২৩) লাম (ل)
সংযোগ / প্রবাহমান সংলগ্নতা / উদ্দেশ্যগত সংযোগ / ধারাবাহিক লিংক / দিকযুক্ত সম্পর্ক।
২৪) মীম (م)
আবদ্ধতা / পরিবেষ্টন / সীমানাবদ্ধ ধারণ / বেষ্টিত অবস্থা / ধারণকারী ক্ষেত্র।
২৫) নূন (ن)
উদ্ভব / বীজ / প্রাথমিক চিহ্ন / সূচনামূলক অস্তিত্ব / সম্ভাবনার চিহ্ন।
২৬) হা (ه)
উপস্থিতি / নির্দেশ / অস্তিত্বের ইশারা / দূরবর্তী সত্তার সংকেত / পরিচয়ের আভাস।
২৭) ওয়াও (و)
সংযোগ / বহির্মুখী প্রসার / যোগসূত্র / সমান্তরাল যুক্তি / সম্প্রসারিত সম্পর্ক।
২৮) ইয়া (ي)
নিকটতা / অন্তর্মুখী টান / ঘনিষ্ঠ সংযোগ / অভ্যন্তরীণ আকর্ষণ / অন্তর্লীন সম্পর্ক।
খুব গুরুত্বপূর্ণ কথা হলো, এই ধারাগুলো অর্থ না, এগুলো অর্থের দিক। অক্ষর = শব্দ নয়। অক্ষর = দিক। রুট = দিকগুলোর নির্দিষ্ট জ্যামিতি। শব্দ = সেই জ্যামিতির বাস্তব রূপ। যাকে আমরা শব্দার্থ বলে জানি।

তাই “এক শব্দ = এক রুট = এক ধারা” সম্ভব, কিন্তু “এক অক্ষর = এক শব্দ” সম্ভব নয়। এখানে ‘এক রুট = এক শব্দ’ বলতে একটি স্থির ধারণাগত কোর (conceptual core) বোঝানো হয়েছে, কোনো একক ভাষিক রূপ নয়। এই কোরটি বিভিন্ন আয়াতে প্রয়োগভেদে রূপান্তরিত হলেও তার মৌলিক অর্থধারা অপরিবর্তিত থাকে। এটা করলে ভাষা ভেঙে পড়েনা। প্রি-গ্রাম্যাটিকাল আরবিতে শব্দের গঠন (structural composition) অর্থ নির্ধারণে একটি মৌলিক ভূমিকা পালন করত। ব্যাকরণ ছিল পরবর্তী বিশ্লেষণী স্তর। যদি এই মডেল ধারাবাহিকভাবে পরীক্ষায় সমর্থিত হয়, তবে প্রতিটি রুটের জন্য একটি স্থিতিশীল বাংলা কোর-ধারণা নির্ধারণ করা সম্ভব হতে পারে। এই ২৮ অক্ষরের মানচিত্র ব্যবহার করলে, কুরআনের বিভিন্ন আয়াতে একই রুটের প্রয়োগে অধিক ধারাবাহিকতা ও অভ্যন্তরীণ সামঞ্জস্য প্রদর্শন করতে সক্ষম হতে পারে। একটি রুটের জন্য একটি স্থিতিশীল কোর নির্ধারণ সব আয়াতে প্রয়োগ পরীক্ষাযোগ্য। ফলে একই রুটের জন্য প্রসঙ্গভেদে সম্পূর্ণ ভিন্ন ভিন্ন অর্থ আরোপের প্রয়োজন কমে যেতে পারে। তবে অতিরিক্ত অক্ষর, শব্দগঠন পরিবর্তনের ফলে অর্থের স্বাভাবিক শব্দার্থ পরিবর্তন ঘটতে পারে। যদি না মূল রুট অক্ষরের সাথে অতিরিক্ত অক্ষর যুক্ত হয়। এই প্রস্তাবিত মানচিত্রের মূল্যায়নের প্রধান মানদণ্ড হবে এর অভ্যন্তরীণ সামঞ্জস্য (internal consistency) এবং কুরআনের শব্দসমূহে এর ধারাবাহিক প্রয়োগযোগ্যতা এবং ব্যাখ্যাগত সক্ষমতা। ভবিষ্যতে যদি অন্য কোনো মডেল একই বা অধিক মাত্রার ধারাবাহিকতা ও ব্যাখ্যাগত সামঞ্জস্য প্রদর্শন করতে পারে, তবে সেটিও সমানভাবে বিবেচনার যোগ্য হবে।
