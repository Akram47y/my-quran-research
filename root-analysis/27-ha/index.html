২৭/১. রুট: هـ د ي (হ-দ-য়)

কুরআনে মোট আগমন: ৩১৬ বার
মূল অর্থ: দিশা / দিশাপ্রাপ্ত / দিশাদাতা
মূল ধারণা: সঠিক পথের দিশা দেওয়া, লক্ষ্য বা গন্তব্যের দিকে পথ বা চিহ্ন সুনির্দিষ্ট করে দেওয়া।

*(মূল শব্দ "দিশা"-কে স্থির রেখে পদ ও কাল অনুযায়ী সামান্য ব্যাকরণগত রূপান্তর করলে এটি সব প্রেক্ষাপটেই মানানসই হয়)*

মূল রুট থেকে আসা শব্দসমূহ:

هُدًى হুদা = দিশা
هَادٍ / الْهَادِي হাদিন / আল-হাদী = দিশাদাতা
اهْتَدَى / يَهْتَدِي ইহতাদা / ইয়াহতাদী = দিশাপ্রাপ্ত হওয়া
أَهْدَى আহদা = অধিকতর দিশাপ্রাপ্ত
